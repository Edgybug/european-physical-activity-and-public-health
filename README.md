
# Physical Activity and Public Health in Europe

## Project Overview

This project investigates the relationship between physical inactivity,
obesity prevalence, and economic development across European countries.

The analysis focuses on 2022 and combines data from the World Health
Organization (WHO) and Eurostat.

## Research Questions

1. Is physical inactivity associated with obesity prevalence?
2. Is GDP per capita associated with physical inactivity?
3. Is GDP per capita associated with obesity prevalence?

## Data Sources

- WHO – Physical inactivity indicators
- Eurostat – Obesity prevalence
- Eurostat – GDP per capita

## Project Structure

- `data/raw/` – Original datasets
- `data/processed/` – Cleaned and transformed datasets
- `notebooks/` – Data exploration, preparation and analysis
